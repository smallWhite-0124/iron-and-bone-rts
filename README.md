# 铁与骨：2.5D 横版 RTS 原型

## 在线试玩

- 游戏地址：<https://smallwhite-0124.github.io/iron-and-bone-rts/>
- 源码仓库：<https://github.com/smallWhite-0124/iron-and-bone-rts>

一个无外部依赖的 Canvas 2.5D 横版 RTS 可玩原型。

## 运行

```powershell
node server.js
```

打开 <http://127.0.0.1:4173>。

## 当前系统

- 骑士团、骷髅族、秘法教团、特战部队四个阵营
- 秘法教团：术士、巫师、秘术师、希拉、远古巨兽，以及巫师召唤的灵魂剑士
- 特战部队：特警、防爆警、特种兵、坦克、直升机
- 粗描边手绘火柴人视觉；人形单位使用髋、膝、脚两段关节步态
- 真正的 2.5D：约 190 像素纵深，单位在 X/Y 双轴移动、二维索敌、碰撞和前后遮挡
- 地面单位会主动绕行己方建筑，避免被兵营和矿机卡住
- 3200 像素长地图，支持镜头水平移动
- 建筑自由放置，不受固定建筑位限制
- 己方建筑边界会随最前排士兵推进而扩张
- 建筑不能放在边界前方，且建筑之间必须留出空地
- 放置模式会画出与碰撞检测完全一致的禁建椭圆
- 点击兵种卡一次，训练队列增加一个单位
- 每个兵营独立训练队列，最多 5 个
- 军队人口上限由兵营数量和等级决定
- 兵营升级会提高人口上限和训练速度
- 建筑升级、右键拆除与 50% 资源返还
- 战斗、倒地、冲锋与复活系统
- 命中停顿、受击僵直与按质量衰减的击退
- 重击镜头震动、方向性火花、冲击星芒和落地扬尘
- 程序化 Web Audio 刀剑、枪械、魔法与爆炸反馈
- 敌方 AI 会自由选址建造、升级和手动排队生产
- 60 FPS 渲染上限、粒子数量上限与帧循环异常保护
- HUD 与 Canvas 等比缩放，窄屏和手机端不会被裁切
- 自动存档与页面重载恢复（每个浏览器标签页独立，避免多开串档）
- 视觉细节增强：天空层次、环境道具、建筑旗帜、单位装甲与清晰剪影
- 武器采用手部锚点旋转，剑、长枪、火枪、法杖和盾牌会跟随手臂握持
- 四阵营使用独立轮廓语言：骑士重甲披风、骷髅骨肋破布、秘法层叠长袍、特战战术装备
- 骨恶龙重做为带翼骨、长颈头骨、胸腔、利爪、长尾与喷火口部的骨骼飞龙
- 骑兵增加马甲、鞍毯和骑手披风；坦克与直升机增加装甲板、履带、座舱和武器细节

## 人口公式

```text
军队上限 = 8 + Σ(8 + 5 × (兵营等级 - 1))
```

只有建造完成并存活的兵营会提供人口。

## 操作

- 长按鼠标左键拖动：用自由图形套索圈选己方士兵
- `A`：进攻
- `H`：驻守
- `R`：撤退
- `←` / `→`、鼠标滚轮：移动镜头
- `Space`：暂停或继续
- `Esc`：取消建筑放置
- 左下角建筑卡：选择后在己方建筑边界内点击空地放置
- 中间兵种卡：每次点击向当前兵营队列加入一个该兵种
- 点击己方建筑：查看属性、训练队列并升级
- 点击顶部“音效 开/关”：切换程序化战斗音效
- 点击顶部“新局”：返回阵营选择界面
- 右键己方建筑：拆除，并返还建筑、升级和剩余训练队列总投入的 50%
