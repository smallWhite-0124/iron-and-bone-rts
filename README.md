# 铁与骨：2.5D 横版 RTS 原型

一个无外部依赖的 Canvas 2.5D 横版 RTS 可玩原型。

## 运行

```powershell
node server.js
```

打开 <http://127.0.0.1:4173>。

## 当前系统

- 骑士团与骷髅族阵营选择
- 粗描边火柴人视觉与步行动画
- 真正的 2.5D：约 190 像素纵深，单位在 X/Y 双轴移动、二维索敌、碰撞和前后遮挡
- 地面单位会主动绕行己方建筑，避免被兵营和矿机卡住
- 3200 像素长地图，支持镜头水平移动
- 建筑自由放置，不受固定建筑位限制
- 己方建筑边界会随最前排士兵推进而扩张
- 建筑不能放在边界前方，且建筑之间必须留出空地
- 放置模式会画出与碰撞检测完全一致的禁建椭圆
- 点击兵种卡一次，训练队列增加一个单位
- 每个兵营独立训练队列，最多 5 个
- 军队人口上限由兵营数量和等级决定
- 兵营升级会提高人口上限和训练速度
- 建筑升级、右键拆除与 50% 资源返还
- 战斗、倒地、冲锋与复活系统
- 敌方 AI 会自由选址建造、升级和手动排队生产
- 60 FPS 渲染上限、粒子数量上限与帧循环异常保护

## 人口公式

```text
军队上限 = 8 + Σ(8 + 5 × (兵营等级 - 1))
```

只有建造完成并存活的兵营会提供人口。

## 操作

- 长按鼠标左键拖动：用自由图形套索圈选己方士兵
- `A`：进攻
- `H`：驻守
- `R`：撤退
- `←` / `→`、鼠标滚轮：移动镜头
- `Space`：暂停或继续
- `Esc`：取消建筑放置
- 左下角建筑卡：选择后在己方建筑边界内点击空地放置
- 中间兵种卡：每次点击向当前兵营队列加入一个该兵种
- 点击己方建筑：查看属性、训练队列并升级
- 右键己方建筑：拆除，并返还建筑、升级和剩余训练队列总投入的 50%
